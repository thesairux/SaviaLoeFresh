# SavialoeFresh

Sitio web de **SavialoeFresh** — infusiones de aloe vera 100% natural combinadas con hierbas y frutas.

*Cuida tu cuerpo, nutre tu esencia.*

## Contenido

- `index.html` — el sitio completo, con el logo.
- `assets/` — imágenes originales de la marca como respaldo.

## Ver en local

Abre `index.html` en el navegador, o levanta un servidor simple:

```bash
python -m http.server 5173
```

## Publicación

Es un sitio estático: se puede publicar en Vercel, Netlify o GitHub Pages sin compilación.

Las fotos de ambientación provienen de [Unsplash](https://unsplash.com) (licencia de uso libre).
